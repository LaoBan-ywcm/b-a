# Domain Docs

## 布局

本仓库采用 single-context：
- `GLOSSARY.md`：仓库根目录的领域术语表。
- `docs/adr/`：架构决策记录。

## 阅读规则

探索代码前，读取术语表及与当前任务相关的 ADR。
文件不存在时直接继续；由 domain-modeling 技能在术语或决策明确后
按需创建，不预先生成占位文档。

## 使用术语

issue 标题、方案、假设和测试名称使用术语表定义的词汇。
需要的概念尚未定义时，先判断是否误用了项目外的术语；
确有缺口则记录给 domain-modeling。

## 决策冲突

方案与已有 ADR 冲突时，明确指出 ADR 编号、冲突内容和重新讨论的理由，
不要静默覆盖既有决策。
